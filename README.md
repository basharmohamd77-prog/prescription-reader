# قارئ الوصفات الطبية الذكي

## التشغيل الحقيقي على Cloudflare Pages
1. أنشئ مفتاح Gemini API من https://aistudio.google.com/app/apikey (قد تنطبق حدود أو رسوم استخدام).
2. انشر المشروع على Cloudflare Pages باستخدام Git integration أو Wrangler حتى يتم نشر مجلد `functions` كـ Pages Function. Direct Upload البسيط قد لا يبني Functions.
3. من إعدادات Pages > Settings > Variables and Secrets أضف Secret باسم `GEMINI_API_KEY` وضع المفتاح كقيمة، ثم أعد النشر.
4. افتح الموقع وارفع صورة وصفة واضحة. المعالجة تتم في الخادم عبر Gemini، وليس في المتصفح.

## الملفات
- `index.html`: الواجهة العربية.
- `style.css`: التصميم المتجاوب.
- `app.js`: رفع الصورة وعرض/تحرير/نسخ النتيجة.
- `functions/api/read-prescription.js`: API آمن نسبيًا يستدعي Gemini من الخادم، ولا يكشف المفتاح للمتصفح.

## تنبيه مهم
هذه أداة تجريبية للتفريغ البصري فقط. يمكن للذكاء الاصطناعي أن يخطئ في قراءة اسم الدواء أو التركيز أو الأرقام حتى لو بدا النص واضحًا. لا تستخدم النتيجة لصرف أو تناول الدواء قبل مطابقتها مع الأصل بواسطة طبيب أو صيدلي. لا ترفع بيانات مرضى دون موافقة مناسبة. الحزمة لا توفر بعد تسجيل مستخدمين أو سجل تدقيق أو اعتمادًا سريريًا أو ضمان دقة. يلزم اختبار سريري مستقل ومراجعة خصوصية قبل الاستخدام المهني.
